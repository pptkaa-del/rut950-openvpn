# rut950-openvpn

Быстрое развёртывание OpenVPN-сервера на VPS для удалённого доступа к
устройствам, подключённым к роутеру **Teltonika RUT950** (подходит и для
RUT240/RUT955/RUTX и других роутеров на RutOS).

Роутер часто стоит на мобильном интернете с «серым» IP — подключиться к нему
напрямую нельзя. Решение: роутер сам подключается к вашему серверу, а вы
подключаетесь туда же и видите его локальную сеть.

```
  Ваш ПК / телефон                VPS (белый IP)                RUT950 (SIM, серый IP)
 ┌───────────────┐   OpenVPN   ┌──────────────────┐   OpenVPN   ┌──────────────┐  LAN  ┌────────────┐
 │ 10.8.0.3      │────────────▶│ OpenVPN-сервер   │◀────────────│ 10.8.0.2     │───────│ Устройство │
 │               │             │ 10.8.0.1         │             │ 192.168.50.1 │       │ .50.100    │
 └───────────────┘             └──────────────────┘             └──────────────┘       └────────────┘
          ping 192.168.50.100  ──────────────────────────────────────────────────────────▶
```

## Возможности

- Установка одной командой: OpenVPN 2.5+, Easy-RSA PKI, systemd, iptables/ufw.
- `add-router` — сертификат для роутера + маршрутизация его LAN-подсети
  (`iroute` / `route` / `push route`) — всё автоматически.
- `add-client` — готовый `.ovpn` для Windows/Linux/macOS/Android/iOS.
- Несколько роутеров с разными подсетями на одном сервере.
- Файлы для RutOS отдельно: `ca.crt`, `*.crt`, `*.key`, `ta.key`.
- Шифры, совместимые со старыми (OpenVPN 2.4) и новыми прошивками RutOS.
- Отзыв доступа (`revoke`) через CRL.

## Требования

- VPS с белым IPv4, **Ubuntu 22.04+ или Debian 11+**, root-доступ.
- Открытый порт **1194/UDP** (проверьте firewall в панели хостера).
- RUT950 с доступом в интернет.

## Быстрый старт

### 1. Сервер

```bash
git clone https://github.com/<ваш-логин>/rut950-openvpn.git
cd rut950-openvpn
chmod +x openvpn-rut.sh
sudo ./openvpn-rut.sh install
```

Параметры (необязательно):

| Параметр | По умолчанию | Описание |
|---|---|---|
| `--port` | `1194` | порт сервера |
| `--proto` | `udp` | `udp` или `tcp` (tcp — если оператор режет UDP) |
| `--endpoint` | автоопределение | внешний IP или домен сервера |
| `--vpn-net` | `10.8.0.0` | VPN-подсеть (/24) |

### 2. Роутер

Укажите **LAN-подсеть роутера** (рекомендуется сменить стандартную
`192.168.1.0/24` на уникальную, например `192.168.50.0/24`):

```bash
sudo ./openvpn-rut.sh add-router rut950 192.168.50.0/24
```

Файлы появятся в `/root/openvpn-clients/rut950/`. Настройка RUT950 —
пошагово в **[docs/RUT950.md](docs/RUT950.md)**.

### 3. Ваш компьютер

```bash
sudo ./openvpn-rut.sh add-client laptop
```

Скачайте `/root/openvpn-clients/laptop/laptop.ovpn`, импортируйте в
[OpenVPN Connect](https://openvpn.net/client/) и подключитесь. Теперь
устройство доступно по локальному адресу, например `192.168.50.100`.

## Команды

```bash
sudo ./openvpn-rut.sh install [--port N] [--proto udp|tcp] [--endpoint HOST] [--vpn-net NET]
sudo ./openvpn-rut.sh add-router <имя> <подсеть/маска>
sudo ./openvpn-rut.sh add-client <имя>
sudo ./openvpn-rut.sh revoke <имя>
sudo ./openvpn-rut.sh list
sudo ./openvpn-rut.sh uninstall
```

## Как это работает

- `client-config-dir ccd/<роутер>` содержит `iroute 192.168.50.0 255.255.255.0` —
  сервер знает, что эта подсеть находится за клиентом-роутером.
- В `server.conf` добавляются `route` (маршрут в ядре сервера) и
  `push "route ..."` (маршрут всем клиентам).
- `client-to-client` — трафик между клиентами и подсетями роутеров
  маршрутизируется внутри OpenVPN.
- Роутеру его собственная подсеть не отправляется (`push-remove`),
  чтобы не конфликтовать с локальным маршрутом.

Файлы на сервере:

| Путь | Что там |
|---|---|
| `/etc/openvpn/server/server.conf` | конфиг сервера |
| `/etc/openvpn/server/ccd/` | настройки роутеров (iroute) |
| `/etc/openvpn/easy-rsa/pki/` | CA и сертификаты |
| `/root/openvpn-clients/` | готовые клиентские файлы |

Диагностика:

```bash
systemctl status openvpn-server@server
journalctl -u openvpn-server@server -f
cat /var/log/openvpn-status.log
```

## Безопасность

- Ключи клиентов (`*.key`, `*.ovpn`) — секретные. Не публикуйте их и не
  коммитьте в репозиторий (`.gitignore` уже настроен).
- Потерянное устройство — сразу `revoke <имя>`.
- Сертификаты выдаются на 10 лет.
